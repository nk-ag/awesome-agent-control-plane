# Contributing to Awesome Agent Control Plane

Thanks for considering a contribution! A few guidelines to keep this list useful:

## Scope

- The tool or resource must be directly related to **governing, securing, or controlling autonomous AI agents** at runtime: identity, policy enforcement, gateways, sandboxing, red teaming, or evaluation.
- Open source is preferred. Proprietary tools are fine if they offer a substantial free tier or are a widely recognized standard.
- No abandonware — tools should have had a commit within the last 12 months.

## Before submitting

Search the existing list to make sure the tool isn't already included.

## Format

```markdown
- **[Tool Name](URL)** - A concise, factual description of what the tool does. Ends with a period.
```

Keep descriptions neutral and specific — no marketing language, no superlatives you can't back up.

## Conflicts of interest

If you're the maintainer or a contributor to a tool you're adding, say so in the PR description. It won't disqualify the entry, but it should be disclosed.
